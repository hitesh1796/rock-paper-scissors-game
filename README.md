# Rock Paper Scissors 🎮

A simple Rock Paper Scissors game built using Python.

The player chooses rock, paper, or scissors, and the computer randomly chooses one as well. The game then determines the winner.

## Features

- User can choose Rock, Paper, or Scissors
- Computer makes a random choice
- Detects ties
- Determines the winner
- Simple command-line interface

## Technologies Used

- Python
- `random` module
- Functions
- Conditional statements

## How to Run

1. Make sure Python is installed.
2. Clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python "rock paper scissors.py"
```

5. Enter your choice when prompted.

## Example

Enter your choice:
`rock`

Computer's choice:
`scissors`

Result:

**You win! 🎉**
